# 年末調整サイト v0.7.0

## v0.7.0
- 提出済みスタッフから管理者へ修正依頼を送信できるようにしました。
- 修正依頼は「修正したい項目・現在の内容・修正後の内容」で送信します。
- 管理画面TOPに修正依頼のお知らせを表示します。
- 管理者が「修正を承認」するとスタッフの状態が「修正依頼」になり、期限内で再編集できます。
- スタッフTOPには「修正が承認されました」と表示します。
- 修正後に再提出すると、承認済みの修正依頼は完了扱いになります。

## 反映手順
1. Supabase SQL Editorで `supabase/migrations/007_staff_correction_requests.sql` を実行。
2. ZIP内のその他の変更ファイルをGitHubへ同じ階層で上書き・追加。
3. Edge Functionの再デプロイは不要です。
