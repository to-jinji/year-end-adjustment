# 年末調整サイト v0.7.1 変更ファイル

## 変更内容
- スタッフTOPの「入力内容の確認・提出」は、全入力項目と必須添付書類が完了するまで無効化。
- 全項目完了後にのみ「入力内容の確認・提出」を有効化。
- 確認・提出画面から、TOPと重複していた「入力状況」一覧を削除。
- 確認・提出画面には入力内容の概要・提出操作・修正依頼関連を引き続き表示。
- 未完了状態で確認・提出画面のURLを直接開いた場合は、年末調整TOPへ戻す。

## 反映
SQL migration / Edge Function再デプロイは不要です。
ZIP内の変更ファイルをGitHubへ同じ階層で上書きしてください。
