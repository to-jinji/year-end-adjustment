# 年末調整サイト v0.5.0

GitHub Pages + Supabase を前提にした TO株式会社向け年末調整サイトです。

## v0.5.0 変更点
- 各入力画面で保存操作をするとボタンを「保存中…」へ切り替え、保存完了後に年末調整TOPへ自動で戻るよう変更。
- 各項目に「必須」「任意」「該当する場合」を表示し、対象外の項目を分かりやすく表示。
- 必要書類ページを入力内容連動に変更。前職・保険料・住宅ローンの回答から必要な書類だけを表示。
- 必須書類の必要数と登録数を表示し、不足時は「必要書類」を完了にできないよう変更。
- 最終提出時にもSupabase側で必須書類不足を再確認するため、画面操作だけで回避できないように変更。
- 管理画面のスタッフ一覧に「回答修正」を追加。
- 管理者が基本情報、本人・所得、配偶者・扶養、保険料控除、前職、住宅ローン控除を修正可能。
- 管理者修正は履歴に保存し、スタッフ側TOPおよび該当入力画面に「管理者による修正」として表示。
- 特に生命保険料控除は管理者修正画面で証明書と照合しやすい一覧・編集形式に変更。
- eLTAX CSV出力は令和8年度レイアウト公開まで保留。個人番号は入力・出力しない方針。

## v0.5.0 反映手順
1. Supabase SQL Editorで `supabase/migrations/005_admin_corrections_required_documents.sql` を実行。
2. `supabase/functions/staff-auth/index.ts` を Edge Function `staff-auth` に上書きして再デプロイ。
3. ZIP内の残りの変更ファイルをGitHubの同じ階層へ上書き・追加。
4. GitHub Pages反映後、スタッフ側と管理者側で動作確認。

## 必要書類の判定
現在は以下を入力内容から自動判定します。
- 前職あり: 前職の源泉徴収票（登録した前職件数分）
- 生命保険・介護医療・個人年金: 生命保険料控除証明書（登録件数分）
- 地震保険・旧長期損害: 地震保険料控除証明書（登録件数分）
- 社会保険料: 社会保険料控除関係書類（登録件数分）
- 小規模企業共済等掛金: 払込証明書（登録件数分）
- 住宅ローン控除あり: 住宅借入金等特別控除関係書類（1件以上）

## 管理者修正履歴
管理者が回答を修正すると `staff_admin_changes` に履歴を保存します。スタッフ本人は自分の修正履歴のみ参照できます。
