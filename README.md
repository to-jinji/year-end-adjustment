# 年末調整サイト v0.4.0

GitHub Pages + Supabase を前提にした TO株式会社向け年末調整サイトです。

## v0.4.0 追加内容
- 管理画面からスタッフ削除
  - 年末調整回答・添付書類・スタッフ用Authアカウントも同時削除
  - 誤操作防止のため、削除時にスタッフIDの再入力が必要
- 管理画面から2026年の年間給与集計を入力
  - 課税支給額合計
  - 社会保険料合計
  - 所得税合計
- スタッフ回答と前職情報を使った2026年分の年末調整試算
  - 給与所得控除
  - 基礎控除
  - 配偶者控除・配偶者特別控除
  - 扶養控除・特定親族特別控除
  - 障害者・寡婦・ひとり親・勤労学生控除
  - 生命保険料控除（令和8年の23歳未満扶養親族特例を含む）
  - 地震保険料控除
  - 社会保険料控除・小規模企業共済等掛金控除
  - 所得金額調整控除
  - 住宅借入金等特別控除額
  - 年調年税額、還付／追加徴収額
- 保険料入力を「新契約／旧契約」に分離
- 住宅ローン入力に「住宅借入金等特別控除額」を追加

## 反映手順
1. Supabase SQL Editorで `supabase/migrations/004_admin_delete_payroll_adjustment.sql` を実行。
2. `supabase/functions/staff-auth/index.ts` を Edge Function `staff-auth` に上書きして再デプロイ。
3. その他の変更ファイルをGitHubへ同じ階層で上書き。
4. GitHub Pages反映後、管理画面の「給与・計算」から年間集計を入力し試算。

## 年末調整計算について
令和8年分の国税庁資料に基づく通常ケースの自動計算です。非居住親族、住宅ローン控除初年度、年末調整対象外となるケースなどは「要確認」と表示します。最終確定前には申告内容・控除証明書・国税庁の年末調整資料と照合してください。

旧バージョンで「生命保険料（一般）」「個人年金保険料」として登録済みのデータは、新契約／旧契約が判定できないため要確認になります。スタッフ側で区分を選び直してください。

## eLTAX給与支払報告書CSV
給与支払報告書・源泉徴収票の統一CSVは、PCdeskが受け付ける当年分の正式レイアウトに完全一致させる必要があります。v0.4.0では年末調整結果を保存する土台まで実装し、eLTAX取込CSV自体は未実装です。令和8年分の正式な「給与支払報告書-源泉徴収票の統一CSVレイアウト仕様書」を確認してから列マッピングを固定します。
