# 年末調整サイト v0.3.0 変更ファイル

v0.2.0 適用済み環境に上書きする変更分です。

## 今回の追加
- スタッフ入力画面を一式実装
  - 基本情報
  - 本人・所得情報
  - 配偶者・扶養
  - 保険料控除
  - 前職・源泉徴収票
  - 住宅ローン控除
  - 必要書類アップロード
  - 入力内容の確認・提出
- 郵便番号7桁から住所を自動取得
  - `zipcloud` の郵便番号検索APIを使用
  - 取得失敗時は手入力可能
- 入力セクションごとの完了状態を保存
- 全項目完了後のみ「提出済み」へ変更
- 提出後はスタッフ側の編集を停止
- 必要書類をSupabase Storageの非公開バケットに保存
  - PDF / JPEG / PNG / HEIC / HEIF
  - 1ファイル10MBまで

## 反映手順
1. Supabase SQL Editorで `supabase/migrations/003_full_staff_forms.sql` を実行。
2. このZIP内の残りのファイルをGitHubへ元の階層のまま上書き・追加。
3. GitHub Pages反映後、テストユーザーで各画面を確認。

今回はEdge Functionの変更はありません。

## スタッフ入力メニュー
1. 基本情報
2. 本人・所得情報
3. 配偶者・扶養
4. 保険料控除
5. 前職・源泉徴収票
6. 住宅ローン控除
7. 必要書類
8. 入力内容の確認・提出

## 書類保管
Migration実行時に `year-end-adjustment-documents` というPrivate Storage bucketを作成します。
ファイルパスはスタッフのassignment UUIDごとに分離し、RLSで本人または管理者だけが閲覧できます。

## 注意
現段階は申告内容の収集画面の実装です。税額・控除額の自動計算や法定帳票PDFの自動生成はまだ実装していません。
