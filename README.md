# 年末調整サイト v0.9.0 変更ファイル

## 変更内容
- 提出済み後は通常状態ではスタッフ入力画面を編集不可に変更。
- 確認画面の「内容を修正する」を押した場合だけ修正モードを開始し、年末調整TOPへ戻る。
- 修正モード中は各入力画面を編集可能にし、確認画面のボタンを「再提出する」に変更。
- 再提出完了後は修正モードを終了し、再び編集不可に戻す。
- 提出済み表示を大きく、緑系の見やすい表示に変更。修正中は別表示。
- 確認画面は「提出日時　提出済みです。」のみ表示。
- 再提出時の管理者への修正通知は従来どおり作成。

## 反映手順
1. Supabase SQL Editorで `supabase/migrations/009_post_submit_edit_mode.sql` を実行。
2. ZIP内のその他の変更ファイルをGitHubへ同じ階層で上書き。
3. GitHub Pages反映後、ブラウザを強制再読み込み。

Edge Functionの再デプロイは不要です。
