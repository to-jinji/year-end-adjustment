# 年末調整サイト v0.8.0

## v0.8.0
- 年末調整TOPは読み込み完了までローディング画面を表示し、初期値の「未入力」が一瞬見える現象を防止。
- 提出済みの場合、TOP下部は「入力内容の確認」と表示。
- 提出後も編集期限まではスタッフ本人が各入力画面を修正可能。
- 修正後に再提出すると、管理画面に「スタッフID・氏名 から提出後の修正があります」と通知。
- 管理者側は承認せず「確認済みにする」のみ。スタッフ側には承認待ち・承認済み表示を出さない。
- 編集期限後は編集不可とし、修正が必要な場合は `jinji@to-job.com` へ修正内容をメール送信する案内を表示。
- スタッフのパスワード入力は初期状態を伏字にし、「パスワードを表示する／隠す」切替を追加。
- スタッフID＋生年月日の本人確認は5回失敗で30分ロックされる旨をログイン画面に明記。
- 管理画面のスタッフ一覧に「本人確認ロック解除」を追加。スタッフID単位のロックを解除可能。
- IP単位のレート制限は攻撃対策として管理画面から個別解除せず、30分で自動解除。

## 反映手順
1. Supabase SQL Editorで `supabase/migrations/008_post_submit_editing_and_unlock.sql` を実行。
2. ZIP内のその他の変更ファイルをGitHubへ同じ階層で上書き・追加。
3. 今回はEdge Functionの再デプロイは不要です。
