# 年末調整サイト v0.13.0

令和8年分「給与所得者の扶養控除等（異動）申告書」の不足項目を追加しました。

## 追加
- 本人：異動年月日・異動事由
- 配偶者：障害者区分（同居特別障害者を含む）
- 扶養親族：同居老親等／その他の老人扶養親族／特定扶養親族／特定親族
- 扶養親族：同居特別障害者
- 退職手当等を有する配偶者・扶養親族：障害者区分、寡婦・ひとり親
- 16歳未満扶養親族：生年月日から自動で住民税欄扱い

## 連動
扶養控除等申告書、本人・所得情報、配偶者・扶養、管理者回答修正は同じDB列を利用します。

## 既存項目で正式様式を再現
- D欄「他の所得者が控除を受ける扶養親族等」
- 16歳未満扶養親族のフリガナ、続柄、生年月日、住所、国外扶養親族、所得見積、異動日・事由

## 今回追加しないもの
- 個人番号：サイトでは収集しない方針を維持
- 給与支払者名称・法人番号・所在地・所轄税務署長・市区町村長：会社固定情報のため、正式帳票出力時に管理者設定として追加予定
- 「従たる給与についての扶養控除等申告書を提出している」：ユーザー指示により画面から除外
