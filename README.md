# 年末調整サイト v0.9.15

## 変更内容
- 本人・所得情報画面で「TO株式会社以外から受け取る給与の見込額」を入力すると、
  その直下に「他勤務先の源泉徴収票」アップロード欄を表示。
- 他勤務先の源泉徴収票は「任意・確認用」。未添付でも年末調整の提出を妨げない。
- アップロード済み書類は同じ画面で表示・削除可能。
- 再アップロード時は同カテゴリの旧ファイルを置き換え。
- 画像はアップロード前に圧縮してSupabase Storageへ保存。PDFはそのまま保存。
- 必要書類画面には新たな必須項目を追加しない（アップロード済み書類一覧には表示される）。
- バージョン表示を v0.9.15 に更新。

## 重要
以前作成した v0.9.14 は未反映とのことなので、v0.9.14は適用せず、このv0.9.15を適用してください。
